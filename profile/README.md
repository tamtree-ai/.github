# Tamtree

[Tamtree](https://www.tamtree.io) is an agent-first workflow orchestrator: durable runs, human
approval steps, and eval gates an AI agent has to pass before it reaches production. This
organisation holds the parts we publish as open source: the StickStage video generator, the
apps and plugins built on Tamtree, and the blog.

| Repository | What it is | Licence |
|---|---|---|
| [**StickStage**](https://github.com/tamtree-ai/stick-stage) | Open-source stick figure comedy video generator. Write a premise, get a captioned, lip-synced 9:16 short. No API keys, runs offline, built on Remotion. | MIT |
| [**t-shoot**](https://github.com/tamtree-ai/t-shoot) | A studio for short-form video: brief a short, approve the script, watch it get made. Built on StickStage and Tamtree. | Apache-2.0 |
| [**shortvideo**](https://github.com/tamtree-ai/shortvideo) | Tamtree plugin for short vertical video: narration, footage and composition as workflow nodes. | Apache-2.0 |
| [**linkedin-connector**](https://github.com/tamtree-ai/linkedin-connector) | Tamtree plugin that publishes LinkedIn posts from a workflow and returns the post URN and URL. | Apache-2.0 |
| [**blog**](https://github.com/tamtree-ai/blog) | Source of the [Tamtree blog](https://www.tamtree.io/blog/): how the orchestrator is built, and how it compares with n8n, Zapier and Make. | CC BY 4.0 |

Start with [StickStage](https://github.com/tamtree-ai/stick-stage) if you want to make a video
today.
